# University Control Pro v2.5.1

## Telegram chat integration fix
- Исправлена типичная ошибка, когда в поле чата указывался username самого бота.
- Теперь UI явно различает username бота и username группы/канала.
- Добавлено автоматическое обнаружение групп/супергрупп/каналов через Telegram updates.
- При добавлении бота в чат карточка чата сохраняется в `system.sqlite3`; на странице направления появляется кнопка «Подключить и проверить».
- Для уже добавленного бота достаточно отправить любое обычное сообщение в группе, после чего чат появится в списке обнаруженных.
- Тестовая отправка показывает точный текст ошибки Telegram, а не общее сообщение.
